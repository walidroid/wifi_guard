                   WIFI LAB GUARDIAN — WIN32 NATIVE WLAN
                      Administration & Protection Wi-Fi
================================================================================

Bienvenue dans l'assistant d'installation de WiFi Lab Guardian.

Cette application est conçue pour l'administration et la protection stricte des
réseaux Wi-Fi dans les salles informatiques d'établissements scolaires.

ARCHITECTURE HYBRIDE LÉGÈRE & PERFORMANTE :
• GUI Desktop Windows Native : Panneau de contrôle C# (.NET WinForms) ~43 Ko
• Backend Local Autonome : Node.js (v20) avec API Win32 Native WLAN (wlanapi.dll)
• Interface Web Moderne : HTML5 / CSS3 / Vanilla JS (~216 Ko) 100% Hors-ligne
• Empreinte minimale : Zéro dépendance Chromium/Electron, RAM divisée par 5

FONCTIONNALITÉS NATIVES WINDOWS (Zéro script PowerShell / CMD / netsh) :
• Filtrage WLAN par liste blanche et liste noire (WlanSetFilterList)
• Masquage des réseaux Wi-Fi bloqués de l'affichage (WlanSetAutoConfigParameter)
• Priorité absolue et auto-connexion au réseau de laboratoire (WlanSetProfilePosition)
• Verrouillage DACL de création de profils personnels (WlanSetSecuritySettings)
• Surveillance événementielle continue (WlanRegisterNotification)
• Sauvegarde préventive et restauration chirurgicale intégrée

Cliquez sur "Suivant" pour démarrer l'installation sur votre poste.
